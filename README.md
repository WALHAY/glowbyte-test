# Домашнее задание: Разработка REST API для управления задачами

**Цель:** Разработать небольшое backend-приложение на Java с использованием Spring Boot, позволяющее создавать, просматривать, редактировать и удалять задачи.

## Описание задачи

Необходимо реализовать REST API для управления списком задач.

Каждая задача должна содержать:
- Уникальный идентификатор.
- Название задачи.
- Описание задачи.
- Статус выполнения (выполнена / не выполнена).
- Дату и время создания.

## Функциональные требования

Реализовать следующие операции:

1. **Создание задачи** — пользователь отправляет название и описание задачи. Система сохраняет новую задачу, автоматически присваивает ей идентификатор, дату создания и статус «Не выполнена».
2. **Получение списка задач** — система возвращает все задачи с возможностью фильтрации по статусу выполнения.
3. **Получение задачи по ID** — система возвращает подробную информацию о конкретной задаче.
4. **Редактирование задачи** — пользователь может изменить название, описание или статус выполнения существующей задачи.
5. **Удаление задачи** — пользователь может удалить задачу по её идентификатору.

## Работа с базой данных

Для хранения задач использовать встроенную базу данных **H2**.

Кандидат должен самостоятельно:
- Спроектировать таблицу для хранения задач.
- Реализовать взаимодействие приложения с базой данных через **JdbcTemplate** (Spring Data JPA и Hibernate не использовать).
- Настроить автоматическое создание таблицы при запуске приложения (например, через `schema.sql`).

Задачи создаются через API и сохраняются в H2. При получении списка задач приложение должно обращаться к базе данных.

## Технические требования

- Java 17 или выше.
- Spring Boot.
- H2 Database.
- JdbcTemplate (без JPA).
- REST API с использованием JSON.
- Разделение приложения на Controller, Service и Repository.

## Ожидаемый результат

Работающее Spring Boot приложение, которое можно запустить локально и проверить с помощью Postman или Swagger. Все операции должны выполняться с использованием базы данных H2.
